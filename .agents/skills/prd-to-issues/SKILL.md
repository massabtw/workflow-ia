# PRD to Issues

Break down the plan into small, well-bounded tracer-bullet tickets.

See [to-tickets](../to-tickets/SKILL.md) for full vertical slice instructions.

## Issue Structure:
1. **Title**: Short, descriptive title.
2. **Objective**: Why this issue exists.
3. **Scope**: What is included and explicitly what is excluded.
4. **Acceptance Criteria**: Verifiable checks (tests, endpoints, UI state).
5. **Dependencies / Blocked by**: Previous tickets that must land first.
