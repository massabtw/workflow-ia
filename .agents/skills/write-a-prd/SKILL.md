# Write a PRD (Spec)

Synthesize the current architecture discussions and grilling session into a structured Product Requirement Document (PRD) / Spec.

See [to-spec](../to-spec/SKILL.md) for detailed guidelines.

## Structure:
1. Executive Summary & Problem Statement
2. Solution & Core Value Proposition
3. Scope: MVP vs. Future Vision (anti-overengineering guardrails)
4. User Stories & Acceptance Criteria
5. Architectural & Technical Decisions (Modules, DB Schema, Contracts)
6. Testing & Quality Decisions
